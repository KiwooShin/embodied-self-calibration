# Finding a teacher segment in DROID

This is an offline measurement audit. It tests whether a gripper-state transition can locate a drawer-opening demonstration. It does not evaluate an interactive policy on DROID, identify contact forces, or establish metric drawer motion from video.

The pinned LeRobot mirror contains 92,233 episodes. A case-insensitive exact match to the task pattern in sample.py selected 132 entries. The film uses the first three in source metadata order (290, 877, 2081). Raw camera frames and measured gripper values are aligned by frame index at 15 Hz. The displayed opening intervals were chosen by visual review across multiple cameras. They bracket visible change and are not precise contact annotations. A candidate trigger requires the observed gripper channel to cross upward through 0.1. It triggered at frame 102 in episode 877. The observed channel was constant in the other two excerpts and across their full episodes. This small ordered sample estimates no population-wide detection rate.

Run sample.py with an external cache directory and a fresh output JSON. It downloads the source metadata, episode parquet files, and three camera views for each selected trial using requests. The script requires NumPy and PyArrow. Run film.py with the JSON, cache, and new MP4 path using Pillow and FFmpeg. Only the derived report and attributed montage are published here.
